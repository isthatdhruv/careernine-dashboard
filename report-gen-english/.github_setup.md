# GitHub Repository Setup Guide

## Step 1: Create New Private Repository

1. Go to https://github.com/career-9 (or your organization)
2. Click "New repository"
3. Repository name: `career-9-report-logic` (or your preferred name)
4. Description: "Career Assessment Report Generation Pipeline"
5. Set to **Private**
6. **DO NOT** initialize with README, .gitignore, or license (we already have these)
7. Click "Create repository"

## Step 2: Add Remote and Push

After creating the repository, GitHub will show you commands. Use these:

```bash
# Add the remote (replace with your actual repo URL)
git remote add origin https://github.com/career-9/career-9-report-logic.git

# Or if using SSH:
# git remote add origin git@github.com:career-9/career-9-report-logic.git

# Verify remote
git remote -v

# Push to GitHub
git push -u origin main
```

## Step 3: Verify

Check that all files are pushed:
- Visit your repository on GitHub
- Verify all core scripts, documentation, and data files are present
- Check that `.gitignore` is working (large files should not be tracked)

## What Will Be Committed

✅ **Core Pipeline Scripts:**
- All phase scripts (00-06)
- master_pipeline.py
- pipeline_menu.py
- Utility scripts (backup_utils.py, student_tracker.py, etc.)

✅ **Documentation:**
- README.md
- COMMANDS.md
- requirements.txt

✅ **Essential Data:**
- data/*.json (reference data)
- Templates/ (report templates)
- images/ (personality/intelligence images)
- final_report_scripts/ (report generation scripts)

❌ **Will NOT be committed (in .gitignore):**
- input.xlsx (data file, too large)
- *.xlsx (data files)
- Reports/ (generated reports)
- graphs/ (generated graphs)
- backups/ (backup files)
- .env (API keys)
- ai_cache/ (cache files)
- __pycache__/ (Python cache)
